Tentang Saya

Siswa kelas Pengembangan Perangkat Lunak dan Gim (PPLG/RPL) di SMKN 7 Baleendah dengan ketertarikan pada Web Development. Saya terbiasa membangun aplikasi web dengan Laravel, merancang REST API, dan menjalankannya di Docker, mulai dari perancangan (UML) sampai implementasi. Saya bekerja secara terstruktur, disiplin, dan senang mempelajari teknologi baru serta berkolaborasi dalam tim.

Pengalaman Proyek

Sistem Peminjaman Alat

Aplikasi web peminjaman alat berbasis REST API dengan tiga peran pengguna. Admin mengelola user, kategori, alat, dan memantau log aktivitas. Petugas menyetujui pengajuan, memantau pengembalian, dan mencetak laporan. Peminjam memilih alat dari katalog, mengajukan peminjaman, lalu mengajukan pengembalian. Backend dibangun dengan Laravel dan dijalankan memakai Docker Compose, dilengkapi diagram UML untuk perancangan.

  • Laravel
  • REST API
  • Docker
  • Multi-role
  • UML

Kode: github.com/IVALKUDUS/API

Desain Aplikasi Restoran Online

Prototype UI/UX aplikasi restoran online yang memudahkan interaksi antara pengguna dan restoran. Alurnya mencakup login akun, daftar menu beserta harga, riwayat pembelian, dan pemesanan makanan dari rumah.

  • UI/UX
  • Prototype
